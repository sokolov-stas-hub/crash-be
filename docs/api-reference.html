0 Setup — фундамент

На цьому стеку (Vite + React + TS + Zustand + React Query + socket.io-client) завжди робимо три речі першими: централізований fetch wrapper, один socket на весь застосунок, типи з контракту бекенду.

0.1 src/lib/apiClient.ts

import { useAuthStore } from '@/stores/auth';

const BASE = import.meta.env.VITE_API_URL; // https://crash-be-stas.fly.dev

export async function api<T>(path: string, init?: RequestInit): Promise<T> {
  const apiKey = useAuthStore.getState().apiKey;
  const res = await fetch(`${BASE}${path}`, {
    ...init,
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': apiKey ?? '',
      ...init?.headers,
    },
  });
  if (res.status === 401) {
    useAuthStore.getState().logout();
    throw new Error('UNAUTHORIZED');
  }
  if (!res.ok) {
    const { error } = await res.json().catch(() => ({ error: res.statusText }));
    throw new Error(error);
  }
  return res.json();
}

0.2 src/lib/socket.ts

import { io, Socket } from 'socket.io-client';
import { useAuthStore } from '@/stores/auth';

let socket: Socket | null = null;

export function getSocket(): Socket {
  if (socket) return socket;
  const apiKey = useAuthStore.getState().apiKey;
  if (!apiKey) throw new Error('Cannot connect WS without apiKey');
  socket = io(import.meta.env.VITE_WS_URL, { auth: { apiKey } });
  return socket;
}

export function disconnectSocket() {
  socket?.disconnect();
  socket = null;
}

1 REST endpoints

GET /api/health

⏰ Коли викликати: ніколи з frontend в normal flow. Це для моніторингу / Fly health checks.

Auth: не потрібен.

Response: { "ok": true } з 200.

Приклад (опціонально, якщо хочеш "Server status" індикатор):

const { data } = useQuery({
  queryKey: ['health'],
  queryFn: () => api<{ ok: boolean }>('/api/health'),
  refetchInterval: 30_000,
});
GET /api/balance

⏰ Коли викликати: ОДИН РАЗ при старті застосунку, після того як юзер ввів API Key. Далі баланс оновлюється з WS-подій (bet:placed.balance, bet:cashedOut.balance, bet:lost.balance) — не робити refetch після кожного раунду.

Auth: X-API-Key обов'язково. Без нього → 401.

Response: { "balance": 10000 }

Приклад (React Query + Zustand sync):

// src/hooks/useBalance.ts
import { useQuery } from '@tanstack/react-query';
import { api } from '@/lib/apiClient';
import { useGameStore } from '@/stores/game';

export function useBalanceInit() {
  const setBalance = useGameStore(s => s.setBalance);
  return useQuery({
    queryKey: ['balance'],
    queryFn: async () => {
      const { balance } = await api<{ balance: number }>('/api/balance');
      setBalance(balance); // sync to Zustand для real-time updates
      return balance;
    },
    staleTime: Infinity, // не refetch'имо — оновлюємо з WS
  });
}
GET /api/rounds/recent?limit=20

⏰ Коли викликати: при старті — для початкового заповнення стрічки crash points зверху екрану. Далі підтримувати локально через round:crash event.

Auth: X-API-Key.

Response:

{
  "rounds": [
    { "roundId": "round_24", "crashPoint": 1.20, "crashedAt": "2026-05-04T07:35:22Z", "tier": "low" },
    { "roundId": "round_23", "crashPoint": 10.24, "crashedAt": "2026-05-04T07:35:04Z", "tier": "high" }
  ]
}

tier: 'low' (red, < 1.5×) | 'mid' (orange, 1.5–3×) | 'high' (green, ≥ 3×). Класифікація на сервері — фронт не реіменує.

Приклад (initial load + live append через Zustand):

// src/stores/recent.ts (Zustand)
interface RecentState {
  rounds: Array<{ roundId: string; crashPoint: number }>;
  setInitial: (rounds: RecentState['rounds']) => void;
  prepend: (round: { roundId: string; crashPoint: number }) => void;
}
export const useRecentStore = create<RecentState>(set => ({
  rounds: [],
  setInitial: rounds => set({ rounds }),
  prepend: r => set(s => ({ rounds: [r, ...s.rounds].slice(0, 20) })),
}));

// у App.tsx
useEffect(() => {
  api<{ rounds: any[] }>('/api/rounds/recent?limit=20')
    .then(r => useRecentStore.getState().setInitial(r.rounds));
  const s = getSocket();
  s.on('round:crash', (e: { roundId: string; crashPoint: number }) => {
    useRecentStore.getState().prepend({ roundId: e.roundId, crashPoint: e.crashPoint });
  });
}, []);

2 WebSocket: Server → Client (12 events)

SERVER → CLIENT round:state

⏰ Коли: на connect + на reconnect. Це твоя реакція на reconnect — повний snapshot, треба з нього відновити стейт.

Payload:

interface RoundStateEvent {
  phase: 'waiting' | 'running' | 'crashed';
  roundId: string;
  startedAt: string | null;
  endsAt: string | null;
  currentMultiplier: number;
  crashPoint: number | null;
  yourBet: { ... } | null;
  players: PublicPlayer[];      // CHANGED: replaces playerCount
}

Приклад:

// src/hooks/useGameSocket.ts
import { useEffect } from 'react';
import { getSocket } from '@/lib/socket';
import { useGameStore } from '@/stores/game';

export function useGameSocket() {
  useEffect(() => {
    const s = getSocket();
    const set = useGameStore.getState();

    s.on('round:state', (e: RoundStateEvent) => {
      // Повний reset — це snapshot
      set.setPhase(e.phase);
      set.setRoundId(e.roundId);
      set.setMultiplier(e.currentMultiplier);
      set.setStartedAt(e.startedAt ? new Date(e.startedAt) : null);
      set.setEndsAt(e.endsAt ? new Date(e.endsAt) : null);
      set.setCrashPoint(e.crashPoint);
      set.setMyBet(e.yourBet);
      set.setPlayers(e.players);
    });

    return () => { s.off('round:state'); };
  }, []);
}
SERVER → CLIENT round:waiting

⏰ Коли: перехід у фазу прийому ставок (~10 сек). Це сигнал "відкривай Bet Panel".

Payload:

interface RoundWaitingEvent {
  roundId: string;
  endsAt: string;
  players: [];                         // always empty (новий раунд, лист скинуто)
}

Приклад (з countdown):

s.on('round:waiting', (e: RoundWaitingEvent) => {
  useGameStore.getState().setPhase('waiting');
  useGameStore.getState().setRoundId(e.roundId);
  useGameStore.getState().setEndsAt(new Date(e.endsAt));
  useGameStore.getState().setMultiplier(1.0);
  useGameStore.getState().setMyBet(null);
});

// у компоненті:
function Countdown() {
  const endsAt = useGameStore(s => s.endsAt);
  const [now, setNow] = useState(Date.now());
  useEffect(() => {
    const id = setInterval(() => setNow(Date.now()), 100);
    return () => clearInterval(id);
  }, []);
  if (!endsAt) return null;
  const remaining = Math.max(0, Math.ceil((endsAt.getTime() - now) / 1000));
  return <div>Next round in {remaining}s</div>;
}

SERVER → CLIENT round:tick

⏰ Коли: кожні 200мс під час running (5Hz).

Payload:

interface RoundTickEvent {
  roundId: string;          // round_25
  multiplier: number;       // 1.42
  elapsedMs: number;        // 1230
}

Приклад (Підхід A — простий):

s.on('round:tick', (e: RoundTickEvent) => {
  useGameStore.getState().setMultiplier(e.multiplier);
});

Приклад (Підхід B — плавно через requestAnimationFrame):

function SmoothMultiplier() {
  const targetMult = useGameStore(s => s.multiplier);
  const [displayed, setDisplayed] = useState(1);
  const targetRef = useRef(targetMult);
  targetRef.current = targetMult;

  useEffect(() => {
    let raf: number;
    const animate = () => {
      setDisplayed(prev => prev + (targetRef.current - prev) * 0.2);
      raf = requestAnimationFrame(animate);
    };
    raf = requestAnimationFrame(animate);
    return () => cancelAnimationFrame(raf);
  }, []);

  return <div className="multiplier">{displayed.toFixed(2)}×</div>;
}
⚠️ Важливо: не показувати displayed multiplier > server multiplier. Бекенд робить Math.floor(m * 100) / 100 саме щоб гарантувати "displayed never exceeds true". Якщо інтерполюєш — теж floor'и displayed (а не округлюй).
SERVER → CLIENT round:crash

⏰ Коли: раунд завершився крашем. Через ~5 сек прийде round:waiting для наступного раунду.

Payload:

interface RoundCrashEvent {
  roundId: string;
  crashPoint: number;
  tier: 'low' | 'mid' | 'high';     // NEW
  players: PublicPlayer[];
}

Приклад (з анімацією crash):

s.on('round:crash', (e: RoundCrashEvent) => {
  useGameStore.getState().setPhase('crashed');
  useGameStore.getState().setMultiplier(e.crashPoint);
  useGameStore.getState().setCrashPoint(e.crashPoint);
  // Прелогінити recent rounds:
  useRecentStore.getState().prepend({ roundId: e.roundId, crashPoint: e.crashPoint });
  // Тригер crash-flash анімації:
  useGameStore.getState().setCrashFlash(true);
  setTimeout(() => useGameStore.getState().setCrashFlash(false), 1500);
});
SERVER → CLIENT bet:placed

⏰ Коли: після successful bet:place від цього клієнта. Сервер вже списав з балансу.

Payload:

  betId: string;            // UUID — використай для відстеження
  roundId: string;          // на який раунд ставка
  amount: number;
  autoCashOutAt: number | null;
  balance: number;          // НОВИЙ баланс (вже після debit)

Приклад:

s.on('bet:placed', (e: BetPlacedEvent) => {
  useGameStore.getState().setMyBet({
    betId: e.betId,
    amount: e.amount,
    autoCashOutAt: e.autoCashOutAt,

SERVER → CLIENT bet:cashedOut

⏰ Коли: твій manual bet:cashout пройшов АБО auto-cashout target досягнутий. Виграш зарахований.

Payload:

interface BetCashedOutEvent {
  betId: string;            // твій bet
  multiplier: number;       // на якому x вийшов
  winAmount: number;        // = bet.amount × multiplier
  profit: number;           // = winAmount - bet.amount
  balance: number;          // НОВИЙ баланс (вже з виграшем)
}

Приклад (з UI animation):

s.on('bet:cashedOut', (e: BetCashedOutEvent) => {
  useGameStore.getState().setBalance(e.balance);
  useGameStore.getState().setMyBet(null);  // ставки більше нема
  toast.success(`Cashed out @ ${e.multiplier}× → +${e.profit}`);
  playSound('cashout');
});

📡 Live Players (3 нові public events)

Ці events broadcast'яться УСІМ підключеним клієнтам (на відміну від bet:* які приходять тільки гравцю). Нічого приватного — тільки username (=apiKey), сума, multiplier коли cashed_out.

PublicPlayer тип

interface PublicPlayer {
  username: string;            // === apiKey
  amount: number;
  status: 'placed' | 'cashed_out' | 'lost';
  multiplier: number | null;   // тільки при cashed_out
}
SERVER → CLIENT players:bet

⏰ Коли: будь-який гравець ставить ставку (під час waiting). Broadcast усім.

Payload:

{ username: string, amount: number }

Приклад:

s.on('players:bet', (e) => {
  useLivePlayersStore.getState().addPlayer({
    username: e.username,
    amount: e.amount,
    status: 'placed',
    multiplier: null,
  });
});
SERVER → CLIENT players:cashout

⏰ Коли: будь-який гравець кешає (manual або auto). Broadcast усім.

Payload:

{ username: string, multiplier: number, winAmount: number }

Приклад:

s.on('players:cashout', (e) => {
  useLivePlayersStore.getState().updatePlayer(e.username, {
    status: 'cashed_out',
    multiplier: e.multiplier,
  });
});
SERVER → CLIENT players:lost

⏰ Коли: будь-який гравець не встиг кешаут до crash. Broadcast усім, по одному event на кожного програвшого.

Payload:

{ username: string, amount: number }

Приклад:

s.on('players:lost', (e) => {
  useLivePlayersStore.getState().updatePlayer(e.username, { status: 'lost' });
});

3 WebSocket: Client → Server (2 events)

CLIENT → SERVER bet:place

⏰ Коли: під час phase === 'waiting', юзер натиснув "Place Bet".

Payload:

{
  amount: number;                      // > 0, <= 10000
  autoCashOutAt?: number | null;       // optional, >= 1.01 якщо число
}

Очікувана відповідь: або bet:placed, або bet:rejected.

Приклад (з loading state):

async function handlePlaceBet() {
  const { amount, autoTarget, autoEnabled } = useBetFormStore.getState();
  useGameStore.getState().setActionInFlight(true);
  getSocket().emit('bet:place', {
    amount,
    autoCashOutAt: autoEnabled ? autoTarget : null,
  });
  // Не чекаємо response тут — handler bet:placed/bet:rejected зніме loading
}

function PlaceBetButton() {
  const phase = useGameStore(s => s.phase);
  const myBet = useGameStore(s => s.myBet);
  const inFlight = useGameStore(s => s.actionInFlight);

  if (phase !== 'waiting') return <button disabled>Wait for next round</button>;
  if (myBet) return <button disabled>Bet placed · {myBet.amount}</button>;
  if (inFlight) return <button disabled>Placing...</button>;
  return <button onClick={handlePlaceBet}>Place Bet</button>;
}
CLIENT → SERVER bet:cashout

⏰ Коли: під час phase === 'running' юзер натиснув "Cash Out". Body порожній — сервер знає твою активну ставку.

Payload:

{}  // (або взагалі без аргументів)

Очікувана відповідь: bet:cashedOut (success), або bet:lost (вже встиг краш — race condition), або bet:rejected з not_running.

Приклад:

async function handleCashOut() {
  useGameStore.getState().setActionInFlight(true);
  getSocket().emit('bet:cashout', {});
  // bet:cashedOut / bet:lost / bet:rejected handlers знімуть loading
}

function CashOutButton() {
  const phase = useGameStore(s => s.phase);
  const myBet = useGameStore(s => s.myBet);
  const multiplier = useGameStore(s => s.multiplier);
  const inFlight = useGameStore(s => s.actionInFlight);

  if (!myBet || phase !== 'running') return null;
  const projected = (myBet.amount * multiplier).toFixed(2);
  return (
    <button onClick={handleCashOut} disabled={inFlight} className="cashout-btn">
      {inFlight ? '...' : `Cash Out — ${projected}`}
    </button>
  );
}

4 Загальні правила

⚠️ Server is the source of truth. Не показуй виграш до bet:cashedOut. Не списуй баланс локально до bet:placed. Жодного optimistic update — на відміну від Mines.
⏳ Loading state на in-flight кнопках. Latency 50–200мс! Якщо не дисейблити кнопку поки летить запит — юзер натисне двічі.
🔄 Reconnect strategy. Socket.IO робить auto-reconnect з backoff. На connect приходить round:state — з нього повністю повертаєш стейт. Не намагайся "догнати" множник між дисконектом і reconnect.
📦 Out-of-order events. Перевіряй roundId у tick'ах — якщо приходить tick для НЕ поточного раунду, ігноруй (race condition при перекритті).
💰 Balance синхронізуй ВИКЛЮЧНО з WS-подій після initial /api/balance. Не робити рефетч REST після кожної ставки — баланс є в bet:placed.balance, bet:cashedOut.balance, bet:lost.balance.

5 Шпаргалка

// ═══ Що приходить → куди в Zustand ═══
'round:state'   →  повний reset стейту з snapshot (з players)
'round:waiting' →  phase='waiting', endsAt, players=[]
'round:start'   →  phase='running', startedAt, players snapshot
'round:tick'    →  multiplier (5Hz)
'round:crash'   →  phase='crashed', crashPoint, tier, players
'bet:placed'    →  myBet, balance (player-targeted)
'bet:cashedOut' →  balance, win toast (player-targeted)
'bet:lost'      →  balance, loss toast (player-targeted)
'bet:rejected'  →  toast(message) (player-targeted)
'players:bet'   →  add to live players list (broadcast)
'players:cashout' → update player status + multiplier (broadcast)
'players:lost'  →  update player status to lost (broadcast)

// ═══ Що шлемо ═══
'bet:place'     →  { amount, autoCashOutAt? }     (під час waiting)
'bet:cashout'   →  {}                              (під час running, з активною ставкою)

// ═══ REST ═══
GET /api/balance         →  один раз при старті, далі sync з WS
GET /api/rounds/recent  →  один раз при старті, далі prepend з round:crash (з tier)
GET /api/health          →  опц., для status indicator
GET /api/docs            →  Swagger UI (без auth)
